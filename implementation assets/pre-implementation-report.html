Selected article images

Preserve safe images in the pop-up while keeping speech and highlighting aligned.

StatusReady for implementation: yes
Branchcodex/selection-images
Date2026-10-03

Fast Answer

Cause

The selection already includes HTML. The sanitizer drops IMG and PICTURE, and the image policy permits only embedded data.

Implementation

Rebuild IMG using validated sources and alt text. Keep captions, fit images to the window, and leave image text outside the speech timeline.

Scope

Ordinary copied web article images. Only selected clipboard contents are rendered. Remote images may fail if the site requires authentication or blocks embedding.

Pass Criteria

  • Selected article images appear in document order in the real overlay.
  • Images fit the overlay at normal and narrow window sizes without distortion or horizontal page overflow.
  • Image alt text never enters speech; surrounding words and captions retain exact canonical character mapping.
  • Copied handlers, styles, navigation, unsafe URLs, SVG data, and unrelated source elements are excluded.
  • A second reading clears old images; plain text and tables still render correctly.
