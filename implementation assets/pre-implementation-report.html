Fast Answer

Current state

Clipboard speech works, so TTS is healthy. The installed app is ad-hoc signed as Electron; rebuilds can invalidate its app-specific Accessibility grant.

Implementation path

Expose live shortcut/permission health, retry lost registrations, add a prominent Read selected text action, and instrument only operational metadata.

Main risk

A permanent macOS permission identity requires a stable Developer ID signature. Code can diagnose and recover registration, but cannot grant Accessibility itself.

Pass Criteria

Shortcut health

  • Both accelerators register and are checked while running.
  • Resume/unlock and periodic checks retry a lost registration.
  • Duplicate app launches cannot create competing owners.

Menu fallback

  • Read selected text invokes the same selection path.
  • Permission or registration trouble changes it to a clear warning state.
  • Clipboard reading remains available separately.

PostHog privacy

  • Operational events reach the supplied project.
  • Selected/clipboard text, HTML, email, and secrets are never captured.
  • Anonymous install IDs do not create person profiles.
