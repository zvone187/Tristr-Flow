Implementation and decisions
  • src/richtext.js: preserve IMG, unwrap PICTURE, and rebuild FIGURE/FIGCAPTION. Copy only validated source and literal alt text. Ignore alt text for canonical speech, and split words at image boundaries.
  • Sources allow HTTP, HTTPS, protocol-relative HTTPS, and base64 PNG/JPEG/GIF/WebP/AVIF/BMP. Credentials, app-relative paths, file URLs, script URLs, blob URLs, inline SVG and HTML data are excluded.
  • Images set no-referrer and asynchronous decoding. Copied events, style, classes, IDs, dimensions and srcset are discarded. Rebuilt images hide on load failure.
  • src/overlay.html: allow HTTP(S) image loads while preserving restrictive defaults, script policy and production sandbox isolation.
  • src/overlay.css: fit images to content width without changing aspect ratio; style captions consistently.
  • README and AGENTS.md record image behavior and durable safety constraints.
  • No capture-layer changes were required. Actual Chromium Copy resolves selected relative image paths into absolute clipboard image URLs.

Browser instrumentation and limits
  • The QA plan was created for this feature. All three test IDs are marked passed in the plan.
  • A confirmed loopback HTTP server served source articles to a real Chromium window. The harness selected article contents, used actual browser Copy, checked the pasteboard change count, read the production clipboard reader, and sent captured HTML to the production overlay/preload.
  • The overlay used production CSP, context isolation, disabled Node integration and sandboxing. Assertions checked decoded images, document order, aspect ratio, normal/narrow bounds, exact word and character maps, repeat resets, safe attributes/requests, broken-image behavior, tables and plain text.
  • The original macOS clipboard was restored losslessly, including both original raw formats. Fixture server, windows and temporary clipboard data were cleaned up.
  • Provider audio was replaced by synthetic timing alignment. No paid TTS requests, physical global shortcut, installed-app replacement, signed packaging or release publishing were performed.
  • This source change requires a new app build to reach an installed packaged app. Keep releases signed and notarized with the existing identity.
  • Authenticated, expired, blocked or unavailable image URLs can fail to load. Blob and unsupported data images remain excluded. Captions are spoken; image alt descriptions are visual/accessibility metadata only.
