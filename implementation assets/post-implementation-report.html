Privacy And Design

Schema Before SDK

Unknown events, properties, enum values, secret-like error names, and out-of-range numbers are dropped before PostHog capture.

Anonymous Install

A random install ID is used. Person profiles and IP geolocation remain disabled on every event.

No User Content

No selected/clipboard text, HTML, email, credentials, tokens, URLs, origins, voice IDs, voice names, or free-form renderer values are sent.

Decisions
Meaningful custom events were chosen over Electron DOM autocapture so analytics reflects completed product actions and does not observe arbitrary interface content. The release remains arm64-only because the bundled macOS helper is arm64. Publishing is tag-driven and refuses a tag that differs from package.json.
