The rich-text allowlist replaced every table tag with div. The clipboard-menu path discarded its HTML flavor before rendering.

Safe semantic table/tr/th/td elements, readable cell styling and horizontal overflow, plus clipboard HTML forwarding.

The installed v0.1.4 app has not been replaced. This code needs a signed/notarized desktop release before downloaded users see the fix.

Implementation and decisions

src/richtext.js rebuilds table structure with first-party elements only; it still drops all clipboard attributes and active subtrees. src/overlay.css styles a scrollable table inside the card. src/clipboard-content.js reads text and HTML together, and src/main.js sends both through the existing sanitizer/spoken-text handshake. No legacy path or provider routing changed.

Limits and delivery

The user's installed app was observed actively reading the same flattened table from the screenshot. It was intentionally left running. Native menu and shortcut E2E need a repeat when playback finishes. No PR was requested or created. The repository's AGENTS.md directs validated work to fast-forward into main; packaging here is ad-hoc for local QA, not a public notarized release.
