Decisions
Meaningful custom events were chosen over Electron DOM autocapture so analytics reflects completed product actions and does not observe arbitrary interface content. Exact text, identity, and credential fields are structurally impossible to emit through the catalog. PostHog's Node guidance shaped batching, shutdown, anonymous-person settings, and host configuration.
